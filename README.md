# AgendaPro

Sistema responsivo de gestão de agendamentos desenvolvido com Next.js,
React, TypeScript, Tailwind CSS, Recharts e Lucide.

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Publicação na Vercel

1. Envie os arquivos deste diretório para a raiz do repositório no GitHub.
2. Importe o repositório na Vercel.
3. Selecione **Next.js** como framework.
4. Mantenha o comando de build como `npm run build`.
5. Mantenha o diretório de saída no padrão automático.

O projeto usa Node.js 22 e não exige variáveis de ambiente para a interface.
